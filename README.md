## 内容概览

- 虚拟机管理（QEMU/Virt-Manager 镜像创建与配置）
- Yocto 工程学习笔记与改造指南（RK3568）
- 嵌入式 Linux 学习指南（Bash、U-Boot、内核源码阅读）
- Linux 设备-总线-驱动模型笔记
- AI Coding 测试报告
- 驱动源码阅读学习，与相关延申
