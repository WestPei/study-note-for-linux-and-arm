# 文档重构说明

本文档记录了旧版三份按写作时间线组织的笔记，重构为三份按主题组织的文档的过程。保留此文件以便日后追溯内容来源。

---

## 重构原则

1. **按主题归类**，不再按写作时间线分散：Yocto 工程 → 镜像制作/烧写 → 源码阅读/开发
2. **保留全部技术内容**，仅裁剪纯粹的编辑器基础操作、已标注"遗弃"的内容
3. **消除交叉重复**，同一知识点只在一份文档中详述
4. **仅为结构调整改写过渡语句**，不缩减、不概括原有内容

---

## 内容裁剪说明

以下为旧文档中明确移除的内容：

| 移除的内容 | 原因 |
|:---|:---|
| Vim 基本操作完整章节 | 编辑器操作，与嵌入式 Linux/Yocto 无关 |
| STM32MP157 介绍 | 原文档已标注"遗弃" |
| Ubuntu 虚拟机安装细节 | 一次性环境配置，非知识性内容 |
| 代理配置 (Clash) | 与 Yocto 核心知识无关 |
| `.tar.gz` 格式解释 | 过于基础 |
